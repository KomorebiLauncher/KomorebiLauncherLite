## 本版改了什么

这一版只动一处：整合包里某个 mod 的作者不允许第三方下载时，安装是怎么走完的。

* **先去 Modrinth 按哈希找同一份文件**。这类文件 CurseForge 一律回 403，文件本身在那边拿不到；但同一份字节往往也发布在 Modrinth 上。现在遇到这种文件，启动器拿它自己的 sha1 去 Modrinth 查一次，查到就下载，下载后照旧核对哈希——只有哈希对得上才算数，长得像的替代品不会被当成它。
* **两边都没有才判失败，理由一次说全**。以前一个作者限定分发的 mod 就能让整只包装不上；现在 Entity Culling 这类文件会从 Modrinth 取到，包装得完完整整。真正两边都没有的（例如作者限定分发的整合包本体 zip，Modrinth 上没有对应的 .mrpack），提示会把两句话都给出来：「作者不允许在 CurseForge 之外下载」和「Modrinth 也没有这份文件」，不用再猜是网络还是 key 的问题。
* 规矩没变：包里少文件仍然不算装好，失败时不会留下半个实例。

仍然只发 Windows。已有实例不需要重装。
