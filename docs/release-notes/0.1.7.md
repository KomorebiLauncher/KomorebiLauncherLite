## 本版改了什么

这一版继续收整合包安装的边角：装到一半失败不再留半个实例，失败信息里的数目对得上，下载时官方公布的哈希也终于被用上。

* **装到一半失败的整合包不再留下空壳实例**。以前游戏和加载器装完后，只要包内文件没下载成，`versions\<包名-版本>\` 就留在那儿——启动器里看着像装好了，点启动才发现缺文件。现在这种「本次新建、又没装成」的目录会被删掉；至于你原来就有的实例，重装失败时一个文件都不动，存档更不会。
* **失败信息的「几之几」不再虚高**。包里写了路径却没给下载地址、或者干脆没写路径的条目，本来就不该算进「N 个文件安装失败」，现在分母只数真正尝试安装的条目。
* **下载整合包时用上官方公布的 sha1**。Modrinth 和 CurseForge 的版本接口都带文件哈希，以前读出来就丢了，现在交给下载层核对；对不上会再取一次。顺带修了 CurseForge 那一侧的解析：它的 `algo` 是数字 `1`，不是字符串，所以哈希一直读成空，这条路径等于没校验。
* **`--selftest` 接进了 `ctest`**：在 `build` 目录里一句 `ctest` 就能跑自检，不用记参数；自检用的临时目录放在构建目录里，不往用户的 TEMP 里写东西。

仍然只发 Windows。已有实例不需要重装。
