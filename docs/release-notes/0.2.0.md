## 本版改了什么

这一版动的是启动器怎么放自己的东西，以及怎么发到玩家手里：不再有安装包，数据就在启动器旁边的文件夹。

* **数据就在启动器旁边**。启动器在哪个文件夹，版本、库、资源、账户和设置就放在哪个文件夹。没有「数据目录」这一项，也没有记住选择的指针文件：想搬家就把整个文件夹挪走，想卸干净就把整个文件夹删掉，都不必再想「数据留在别处没删掉」。
* **那个文件夹必须可写**。放在 `Program Files` 这类需要管理员权限的位置时，启动器会直接说「这个文件夹不可写」然后停下，不会退到别的目录默默开始一个新的。退回别处正是以前「换过目录就忘了数据在哪」那类问题的源头，这次索性不留这条路。
* **同一个文件夹只开一个启动器**。再点一次启动器，已经开着的那个窗口会到前面来，第二个进程直接退出——两份启动器同时写 `settings.json` 和实例文件会把它们写坏。放在两个不同文件夹里的启动器互不相干，可以同时开着。
* **不再有安装版**。发布只出单文件版 exe 和 zip 两种包，都是绿色的：解压或放进一个自己能写的文件夹，双击就是全部步骤。以前版本的安装包仍留在 Releases 里，只是不再更新。

仍然只发 Windows。
