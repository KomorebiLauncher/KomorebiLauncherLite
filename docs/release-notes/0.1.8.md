## 本版改了什么

这一版只动一处：从 CurseForge 取整合包时，下载地址是怎么拿到的。

* **地址不再多问一遍**。CurseForge 列文件时本来就带着 CDN 直链，以前读出来就丢掉，再逐个文件去问 `download-url`；现在先用列表里给的那条，只有本来就没给的才回落到端点。装一个整合包少几十次请求。
* **作者不允许第三方下载的文件，说清楚原因**。这类文件那个接口一律回 403，而且响应体是空的——以前界面上只有一句 `server replied with status code 403`，像是启动器坏了或者 key 失效。现在直接写「作者不允许在 CurseForge 之外下载」，指出是这只包的作者用 CurseForge 限定分发，不是网络问题，也不是你的 key 有问题。
* 包内每个 mod 也走同一条路，所以整合包安装同样受益。

仍然只发 Windows。已有实例不需要重装。
