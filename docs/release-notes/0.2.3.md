## 本版改了什么

* **作者不让第三方下载的模组，现在会单独列出来让你自己下**。有些整合包里的文件在 CurseForge 上被设成禁止第三方下载，以前安装会卡在半路。现在整合包照常装完，缺的那些记在版本里：装完会弹出清单，写明模组名、版本号和文件名，点模组名直接打开对应的 CurseForge 文件页；「内容」页也有同一个入口（手动获取（N）），启动页会提示这个整合包还差几个文件。
* **文件丢进 hokora 文件夹就会自己收进去**。清单里的「打开 hokora 文件夹」指向数据目录下的 hokora；下载回来的文件不用改名，放进去就会被认出来：按整合包给出的校验值比对内容，对得上就改成整合包要的文件名放进版本，对不上留在原地说清楚是哪一个。清单开着的时候文件夹一变就重扫，也可以手动点「再看一次」。

仍然只发 Windows。
