## 本版改了什么

先认个错ですの。整合包列文件时，一次只问到最新的五十个，钉在更旧文件上的包就装不成——不是您的手气不好，是本小姐问得太少。这一版把 id 攒起来一次问回去（PCL 也是这么做的），钉住哪个文件都认得出来了。

* **装整合包时，会先问您要哪个版本。** 以前拿的是 API 列在最前面的那个，往往正好是下一个版本的测试版，装完才发现不对。现在弹出选择，类型、日期、大小都写着，默认落在最新的正式版上；往下滚才去取下一页，不必等全部读完。
* **整合包列表一次三十个，带「下一页」。** 以前一口气拉完，翻到后面就卡；现在看多少取多少。

三件都是「问得少」惹出来的。要是您还碰到装不上的包，把名字告诉本小姐嘛～
