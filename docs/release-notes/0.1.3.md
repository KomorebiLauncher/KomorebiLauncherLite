## 本版修好了什么

* **设置里那些「没有输入框」的地方**——内存、窗口宽高、Java 路径、JVM 参数、游戏参数、启动前命令、下载源镜像、实例对话框和整合包搜索框：输入框的边框被主题的样式表整块盖掉了，只剩下文字，看不出哪里能填。现在边框、圆角和聚焦时的描边都画了出来；自检里也加了一条「边框要和底色不一样」的检查，这类看着是空的问题不会再悄悄混进包里。
* **数据目录能换了**（设置 → 数据目录）：可以选到别的盘，选的时候可以复制现有文件、也可以只切换不复制。重启启动器后生效；`%APPDATA%\KomorebiLauncherLite` 里只留一行 `data-root.txt` 记住新位置，删掉它就回到默认。
* 包里不再混进自检截图：之前每次打包会把三张 `selftest-*.png` 一起 zip 进去，现在跟日志一起清掉了。
