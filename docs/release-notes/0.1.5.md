## 本版改了什么

* **换过数据目录之后，启动器不会再把你选过的目录忘掉**。记住「数据在哪儿」的那行 `data-root.txt` 只存在 `%APPDATA%\KomorebiLauncherLite` 里；而换完目录，这个文件夹里已经没有版本、账户和存档了，把它删掉是很自然的动作——一删，启动器下次启动就当成了第一次启动，界面空空如也，看起来就像「复制过去的版本、账户、存档全都没了」。现在同一份指针在 `%LOCALAPPDATA%\KomorebiLauncherLite` 还留着一个副本。
* 原指针没了、副本还在时，启动时会直接说清楚：上次用的是哪个目录，记住它的那个文件已经不在了（那个文件所在的文件夹大概被删了），要不要回去。选「回到那里」会写回指针并自动重启，版本、账户、存档原样回来；也可以选「用默认目录重新开始」，两份指针一起清掉，以后不再问。
* 如果那个目录本身也不在了，就只提示一句、不提问，免得把人引到一个空目录。
* 设置里换目录时同样会写两份指针；`KOMOREBI_DATA` 环境变量的优先级不变，测试脚本照旧完全绕开数据目录。
* 顺带一提，微软账户登录从 0.1.4 起就不需要填应用 ID 了：启动器自带和完整版同一个公共客户端，设备码流程照常走。0.1.3 及更早的版本才会在登录框里要求你去设置里填 ID。
