## 本版改了什么

* **登录不再需要你填应用 ID**。之前设置里有一栏「Microsoft 应用 ID」，把「注册一个 Azure 应用」这件事推给了玩家；实际上自己注册的应用几乎都会被微软拒绝（租户类型不对、没开 public client flows），填了也登不上，只会浪费一次尝试。现在启动器自带应用 ID——和完整版是同一个 Komorebi 应用，走的是设备码流程——那一栏连同提示一起删掉了，设置里少了这一项。
* 登录失败时不再猜原因：对话框原先对「没有应用 ID」单独写了一句指引，现在这种失败不可能发生，剩下的错误原样显示。
* 自检里加了一条检查，确认启动器永远带着应用 ID，免得哪天有人把这个常量删了却没人发现。
