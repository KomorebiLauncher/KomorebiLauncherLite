## 本版改了什么

三处都是装到手里才会碰到的小毛病，上一版的数据目录改动没有回退。

* **日志页会自己刷新了**。以前它只在启动器启动时读一次 `logs` 文件夹，所以先开游戏、再切到日志页，看到的还是启动时那张空列表，得重启启动器才认得刚写下的日志。现在每次打开这一页都会重新读一遍。
* **装完不再停在安装窗口**。安装成功后会自己关掉，回到版本列表并选中刚装好的那个版本。以前窗口停在原地等你点「Done」，而点下去还会把刚装好的版本号一起丢掉，列表看起来毫无变化。
* **进度里的百分号不再重复**。下载进度那行以前显示成 `assets 25%%`，现在就是 `assets 25%`。

仍然只发 Windows。
